# anigo

Терминальный клиент для поиска и просмотра аниме, написанный на Go.

## Возможности

- Интерактивный TUI-интерфейс прямо в терминале
- Поиск аниме через встроенные экстракторы (парсеры источников)
- Переключение между источниками прямо в интерфейсе
- Поддержка нескольких провайдеров через архитектуру фабрики экстракторов

## Установка

### Из релиза

Скачайте бинарник для своей платформы со [страницы релизов](https://github.com/PinguinAdvokat/anigo/releases).

### Сборка из исходников

```bash
git clone https://github.com/PinguinAdvokat/anigo.git
cd anigo
go build ./cmd/...
```

Требуется Go 1.25+.

## Использование

```bash
./anigo
```

Запускает интерактивный интерфейс в терминале. Навигация — стрелки клавиатуры, выход — `q` или `Ctrl+C`.

## Структура проекта

```
cmd/        — точки входа
internal/   — внутренняя логика (экстракторы, UI, модели)
```

## Зависимости

- [tview](https://github.com/rivo/tview) — TUI-фреймворк
- [tcell](https://github.com/gdamore/tcell) — низкоуровневый терминальный рендеринг
- [goquery](https://github.com/PuerkitoBio/goquery) — парсинг HTML
